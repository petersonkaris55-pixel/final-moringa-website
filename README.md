# Ivory Estate Restaurant

# Description
 
 Ivory Estate restaurant is a premium web-based reservation platform desighned to provide a seamless booking experience (table booking website)for luxury travelers.The application features a modern "Glassmorphism" user interface,utilizing translucent layers and blur effects to create a sophisticated, high-end feel.It includes a multi-page navigation system that allows users to explore hotel features(cool/asthetic) and book their most prefered seating space through an interactive reservation form.

# Setup Instructions 
1.clone this repository to your local machine
2.Ensure all project files(index.html,reserve.html,and the css folder)are in the same directory (create in ubuntu)
3.Open index.html in your preferred web browser to view the landing page.
4.create the boiler plate of all 3 files while styling (to your preferred theme making all necessary corrections[debuging])
5.create a script.js having done the following;
a.DOM Manipulation
b.Event Handling
c.Form validation
d.use localStorage

6.Navigate to the "Reservations" page to access the booking system.
7.Test for errors and debug.
